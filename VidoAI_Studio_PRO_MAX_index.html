ⓘ HELP & CAPABILITIES

READ BEFORE EXPORT
How do I start?

Import a video, use the Frame, Color, Motion, Lyrics and Audio tabs, set trim points, then export. Preview updates as you change controls.

Does it upload my video?

No server upload is performed by this page. Your local browser reads the selected file and draws it to the preview canvas.

Why is export WebM?

The browser's MediaRecorder API chooses the supported recording format. This build prefers WebM when available. MP4 is not guaranteed.

Are AI upscaling and stabilization included?

No. The clarity control is a visual preview filter, not AI enhancement. Genuine offline AI needs model files, memory and device support; those are not bundled in this single-file build.

VidoAI Studio · Quick Guide

Import a local video. Adjust the frame, grading, speed and lyric overlay. Use the trim IN/OUT fields to define the exported section. Export happens in real time and may take as long as the clip.

Device note: high resolution and high bitrate can use significant memory and battery. On lower-powered Android phones, start with 480p or 720p.
